# Exploratory Data Analysis (EDA) Project

## Objective
The objective of this project is to analyze the dataset and identify patterns, trends, and relationships using Exploratory Data Analysis techniques.

## Files Included
- raw_dataset.csv
- cleaned_dataset.csv
- eda_analysis.py
- requirements.txt

## Tools and Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Steps Performed
1. Data Cleaning
2. Handling Missing Values
3. Statistical Analysis
4. Data Visualization
5. Correlation Analysis

## Outcome
This project helped in understanding the dataset and improving analytical thinking and data exploration skills.
